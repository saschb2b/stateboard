# Patterns

- [Product landing page](product-landing.md) - An editorial introduction, interactive assessment preview, role routes, and agent maintenance explanation.
- [Product overview](product-overview.md) - One release review summary followed by product features and check coverage, with architecture as optional context.
- [Release review workspace](review-workspace.md) - A candidate review with features, contextual checks and results, and a separate owner decision.
- [Supporting screen contracts](supporting-surfaces.md) - Layout and interaction requirements for boards, settings, sharing, and presentation.
